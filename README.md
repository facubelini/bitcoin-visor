# Visor de cotización de Bitcoin

Precio diario de Bitcoin desde julio de 2010, con hechos clave, ciclos de halving, distancia al máximo histórico, patrones de comportamiento y precio en vivo.

- Todo está en un solo archivo: `index.html`.
- Los datos históricos van incluidos en la página (hasta el 14 nov 2026).
- Al abrirla, la página trae los días siguientes y el precio en vivo desde la API pública de CoinGecko (sin clave). El precio se actualiza cada minuto.
- Si CoinGecko no responde, se muestran los datos guardados.

Publicación: GitHub Pages, rama `main`, carpeta raíz.

Precios en vivo: CoinGecko. Información con fines educativos; no es una recomendación de inversión.
